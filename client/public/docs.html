快速开始

5 分钟完成环境配置，跑通第一个 Agent 任务。按以下步骤依次操作即可。

1. 环境准备清单

系统要求

  • Node.js >= 18.0
  • npm >= 9.0 或 pnpm >= 8.0
  • Git >= 2.30

API Key 配置

在项目根目录创建 .env 文件：

.env
# OpenAI API 配置 OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx OPENAI_MODEL=gpt-4o # 可选：其他 LLM 配置 ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxx

2. 初始化向导

克隆项目

bash
git clone https://github.com/your-org/ai-one-person-company.git cd ai-one-person-company npm install

配置文件修改

编辑 config.json，设置你的 Agent 参数：

json
{ "agents": [ { "name": "IT", "temperature": 0.7 }, { "name": "运营", "temperature": 0.8 }, { "name": "财务", "temperature": 0.3 }, { "name": "行政", "temperature": 0.5 } ] }

启动服务

bash
npm run dev

3. 首次运行验证

预期输出

terminal
✓ 环境检查通过 ✓ API Key 验证成功 ✓ Agent 面板已启动: http://localhost:3000 ✓ 加载 4 个数字员工: IT, 运营, 财务, 行政

常见问题排查

检查 .env 文件中 OPENAI_API_KEY 是否正确复制，确保没有多余空格。可以访问 OpenAI 控制台验证 Key 是否有效。
修改 config.json 中的 port 字段，或运行 lsof -i :3000 查看占用进程并关闭。

角色切换面板

IT 数字员工

职责范围：网站搭建与维护、服务器配置、域名管理、技术选型、代码审查、自动化部署。

适用场景：需要快速搭建产品官网、配置 CI/CD 流程、解决技术债务、选择技术栈。

参数调节建议

框架与模板

解析 OpenClaw 框架与阿里 Copaw 模板的技术原理，支持高级用户二次开发。

架构拓扑

Copaw 模板扩展指南

目录结构

text
copaw-template/ ├── agents/ # Agent 定义目录 │ ├── it-agent.json # IT Agent 配置 │ ├── ops-agent.json # 运营 Agent 配置 │ ├── finance-agent.json # 财务 Agent 配置 │ └── admin-agent.json # 行政 Agent 配置 ├── hooks/ # 扩展钩子 │ ├── before-task.js # 任务执行前钩子 │ └── after-task.js # 任务完成后钩子 ├── plugins/ # 自定义插件 │ └── custom-plugin.js # 示例插件 ├── config.json # 全局配置 └── README.md # 模板说明

扩展钩子位置

在 hooks/ 目录下创建自定义钩子：

javascript
// hooks/before-task.js export default async function beforeTask(context) { // 任务执行前的自定义逻辑 console.log(`准备执行任务: ${context.taskName}`); // 可修改上下文参数 context.params.retries = 3; return context; }

自定义插件接入

在 plugins/ 目录下创建插件，并在 config.json 中注册：

json
{ "plugins": [ { "name": "custom-plugin", "path": "./plugins/custom-plugin.js", "enabled": true } ] }

开发者 FAQ

在 agents/ 目录下创建新的 JSON 配置文件，定义 Agent 名称、系统提示词、参数配置。然后在 config.json 的 agents 数组中添加引用即可。框架会自动加载并注册新 Agent。
OpenClaw 框架内置任务队列，支持并行执行多个 Agent 任务。通过 config.json 中的 concurrency 参数控制并发数量。注意 API 调用频率限制，建议设置合理的并发上限。
1. 降低 temperature 参数提升响应速度；2. 使用流式输出（streaming）减少等待时间；3. 优化系统提示词，减少冗余指令；4. 合理设置 max_tokens 避免过长响应。
支持。修改 agents/ 或 hooks/ 目录下的文件后，框架会自动检测文件变更并重新加载。无需重启服务，但正在执行的任务不会中断。
